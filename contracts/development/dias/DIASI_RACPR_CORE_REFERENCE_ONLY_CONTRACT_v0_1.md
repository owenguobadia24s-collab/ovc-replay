# DIASI RACPR CORE reference-only contract v0.1

## Scope and ownership

WP4B implements RACPR as an embedded proof-resolution library beneath existing RAC claim disposition. It creates no daemon, scheduler, worker fleet, persistence service, repository writer, incident service, or second orchestration state machine. RAC retains assurance-scope authority; CIPR remains the canonical pytest execution substrate; DEVOBS remains the measurement owner; VIT/SIQ/GRT integration semantics are unchanged.

The current parent RAC state is `PILOT_REBASELINED_ACTIVE` with general delta assurance inactive. Accordingly, every WP4B proof, binding, route and projection is separately labelled `REFERENCE_ONLY`. Nothing in this packet can satisfy a decision-bearing RequiredAssuranceSet member, alter the current RAC pilot, contaminate parent RAC qualification evidence, or substitute for reference execution.

## CORE implementation limit

Only Rungs 0–3 are implemented:

- measurement/currentness/evidence-reuse foundations;
- exact collection-membership parity derivation;
- runtime-compatibility equivalence, dependency-complete residual, or reference fallback;
- fresh profile-assurance decomposition into selection, selected execution, orchestration validation, and boundary preservation.

Rungs 4–9 are not implemented. The preregistered ordinary fast-path cohort retains the architectural p90 certificate objective of 60 seconds, but this packet records no measured operational claim and performance never creates proof sufficiency.

## Validity and fallback

A proof is available only when semantic applicability, exact identity, closed completeness, required independence, all currentness dimensions, and a deterministic registered rule PASS. Unknown or unmapped dependency universes, duplicates, loader errors, incomplete residuals, reconciliation-debt breach, common-mode ambiguity, or any failed validity conjunct routes to reference execution.

The fallback ladder is derived proof, dependency-complete residual execution, then reference execution. Reference unavailability is unsatisfied assurance, never PASS. False agreement is never resolved by voting.

## Reserved authority

The first decision-bearing substitution remains reserved to `DIASI-G-RACPR-PROOF-SUBSTITUTION-PILOT`; general compression remains reserved to `DIASI-G-RACPR-ASSURANCE-COMPRESSION-GENERAL`. DGS cutover and retirement remain independently reserved.
