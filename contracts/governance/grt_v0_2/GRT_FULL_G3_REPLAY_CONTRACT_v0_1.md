# GRT Full-G3 Shadow Replay Contract v0.1

## Status
Corrective implementation contract under `OVC-GRT-V0.2-RCCC-CONFORMANCE-IMPLEMENTATION-PLAN-0.2-REVISED-RATIFIED`. Authority effect: **NONE**. It implements existing GRT2-D1..D433 semantics and does not amend or activate them.

## Inputs
A replay consumes an exact predecessor commit and exact candidate/integration commit. Both commits and trees MUST resolve from Git history. Source-bound constitutional inputs include Repository Constitution/rule/root registries, current-state pointers, current PGN authority, workflow governance, immutable B0, exact changed paths and exact repository references.

## Source-bound fact doctrine
Physical observations are evidence, never authority. Current/historical status MUST be resolved from explicit current-state pointers or explicit lifecycle evidence. Ownership/Genesis/dependency facts may be satisfied only from source-explicit or otherwise accepted evidence allowed by the ratified Constitution. Candidate inference, import proximity and filename convention MUST NOT be promoted to current authority. Missing or conflicting required facts are `NOT_EVALUABLE` and fail closed.

## Required full-G3 families
The adapter MUST implement the ratified phases for roots/placement, artifact classification, ownership, Genesis bindings, companions/orphans, dependencies, supersession, current-state/documentation, workflows/tooling and baseline/integrity. A candidate with no applicable subject in a family is still evaluated for that family; absence of an applicable subject is not the same as an unimplemented family.

## Debt transition semantics
Findings are identified by rule and stable logical source subject. In a predecessor/candidate comparison, inherited actionable findings are grandfathered for comparison only. Unchanged or reduced inherited debt passes; resolved debt passes with proof; new, expanded, materially changed or illegally recreated debt fails. This pre-activation comparison does not create a DebtFloor or grant grandfathering authority.

## Replay result
The runner emits exact commit/tree identities, changed paths, family coverage, source-bound adapter errors, would-block findings/debt transitions, status `PASS|FAIL|NOT_EVALUABLE`, measured `GRT_EXACT` duration/peak memory and a semantic canonical hash that excludes runtime measurement fields.

## Qualification and performance
Synthetic/adversarial assurance MUST prove missing source evidence remains unresolved, conflicting owners fail closed, inferred dependencies do not become hard dependencies, orphan/workflow gaps are detected, inherited unchanged/reduced debt passes, new/expanded debt fails, rule-family omission is impossible, and constitutional rule change is operator-reserved. Real replay performance is compared with the frozen G2 `GRTPerformanceBudget`; measurement variance does not change semantic identity.

## Non-enforcement boundary
This contract does not activate Repository Constitution v0.2, DebtFloor generation 0, GRT-EXACT as a required check, PGN adoption, owner reassignment, constitutional semantic change, or any market/scientific/risk/execution authority. GRT2-G3 remains operator-required.
