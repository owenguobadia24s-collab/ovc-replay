# GRT v0.2 Governance Binding Contract — WP3B

Status: **INACTIVE / NON-ENFORCING**. Authority effect: **NONE_GOVERNANCE_PROJECTION**.

WP3B projects ownership and Programme Genesis relationships from explicit evidence. It does not create programme identity, reassign ownership, adopt deferred PGN candidates, or infer current governance from path proximity.

Evidence precedence is: explicit accepted repository decision; native Programme Genesis; ratified/current plan; current machine programme state; accepted supersession/migration lineage; explicit registered package rule; corroborated historical evidence; candidate inference. Same-precedence conflicting values remain `CONFLICTING` and require operator resolution.

Current owner relationships require source/lineage evidence. Candidate or corroborated historical evidence alone remains `CANDIDATE_RELATION`. A current mandatory Genesis crosswalk is satisfied only by native/source-explicit/accepted-lineage evidence; provisional or inferred binding returns `PGN_AUTHORITY_REQUIRED_CURRENT` and does not satisfy conformance.

`OwnershipPartitionProposal` is review evidence only. It must identify a stable scope, proposed owner, complete covered-artifact set, exceptions, impacted owners, exact owner evidence, objections and overlapping authoritative claims. Objection or overlap is `OPERATOR_REQUIRED`. Silence never creates ownership, and WP3B never materializes permanent ownership partitions.
