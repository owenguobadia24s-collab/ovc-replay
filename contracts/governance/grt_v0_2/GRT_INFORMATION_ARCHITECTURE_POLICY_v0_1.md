# GRT Information Architecture Policy v0.1

**Status:** `PROPOSED_UNADMITTED`  
**Authority effect:** `NONE_PRE_ENFORCEMENT`

The root registry records exact observed repository roots without conferring legality. A directory name is not lifecycle or authority evidence.

Forward policy:

1. Every permanent top-level root must ultimately have one registered constitutional disposition.
2. Current canonical content belongs only in roots admitted by an active Constitution.
3. `DEPRECATED_NO_NEW_WRITES` prohibits new canonical writes only after the applicable operator activation.
4. Moves preserve logical artifact identity and must retain lineage.
5. Migration is non-destructive and forward-only; historical bytes and decisions remain addressable.
6. Pre-G3 root and write-policy results are advisory and cannot block integration or create grandfathering.
