# C2P Orthogonal State Axes Contract v0.2
Status: FROZEN_INACTIVE_CONFORMANCE / authority_effect=NONE

Lifecycle, observability and evaluation/evidence state are separate registries/planes.
CENSORING, MISSING, NOT_EVALUABLE, AMBIGUOUS and CONFLICT cannot be collapsed into a lifecycle state.
Censoring does not retire an assertion and missing evidence does not invent a structural terminal time.
