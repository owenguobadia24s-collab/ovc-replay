# C3 inactive reference bridge v0.1 — ESLI-WP4

This surface exists only to prove the minimum ESL vertical path:

`StructuralOccurrence -> C3SemanticProposition -> C3StatementAST -> deterministic rendering + RenderTrace`.

It is **not** the revised C3 runtime. The only maturity reachable in ESLI is `INACTIVE_REFERENCE`. `SHADOW_EVALUATION` and `PRODUCTION_GRAMMAR` require separately governed operator authority and an exact vocabulary-activation registry that this programme intentionally keeps empty.

Upstream StructuralOccurrence identity/state remain immutable. The bridge creates references and composition only. SOI/OrganisationEvidence, CEI/ConstraintEvidence, C2P and C2E clauses are optional and omitted with typed reasons when absent. Family context is never required by the base statement.

`C3ExplanationRecord` is a separate noncanonical sidecar. LLM/generated explanation text is prohibited from proposition, AST, RenderTrace and canonical identity paths.
