# SRFDI-WP9C Corrective Segmentation-Preregistration Supersession v0.1

## Status and authority

`SRFDI-WP9C` is a bounded pre-run correction to the already-frozen SRFD June preregistration. It exists because the WP10 preflight found that the frozen v0.2 preregistration enumerated segmentation methods without freezing enough identity-critical source fields, boundary-pack semantics and parameter surfaces to execute one unique run.

This packet grants **no June benchmark execution authority**. It may use the governing SRFD design, merged implementation contracts and synthetic/golden/adversarial fixtures only. It may not inspect June scientific outputs, fetch provider data, consume Validation, change selectors, promote a family or semantic object, publish a canonical surface, or create probability, risk, exposure or execution authority.

## 1. Supersession rule

The v0.2 preregistration remains immutable historical evidence. This packet creates a compositional v0.3 candidate:

`v0.3 = exact frozen v0.2 base + segmentation_boundary_packs_v0_3`

No representation, distance, family-method, sensitivity, source-population or T0 pairwise/family-grid choice is changed. If `SRFDI-G9C-FREEZE` does not approve `PREREGISTRATION_FREEZE`, v0.3 has no authority effect.

If `SRFDI-G9C-FREEZE` approves the freeze, the prior v0.2 June authorization and token become **SUPERSEDED_UNUSED** because they bind the v0.2 manifest hash. June execution remains denied until a new `SRFDI-G-JUNE-AUTH` decision binds the v0.3 hashes and the exact post-freeze implementation commit.

## 2. Exact segmentation source and chronology contract

All executable C2 segmentation streams are derived from the already-governed `C2LedgerInput` adapter. Streams are partitioned by source release, instrument, side, scope and clock; ordered by `first_valid_time` then `record_id`; and split at explicit source reset markers. Segmentation may never alter population membership.

`RUN_CHANGE_SEGMENTATION` uses the existing deterministic `state_key`, which hashes the exact five-axis C2 payload plus scope. A boundary becomes first-valid at the current record where the state key changes. It is never backdated.

`NULL_BOUNDARY_CONTROL` emits no structural boundaries and produces one censored control segment per uninterrupted source stream. Source reset boundaries remain data-continuity controls and are not counted as structural discoveries.

`C2E_CAUSAL_ADAPTER` remains visible but non-executed because no lawful frozen real-source C2E episode ledger is bound.

`DIRECTIONAL_CHANGE` remains visible but non-executed because the current exact SRFD source binding contains C1/C2 research records and does not bind a lawful price value field for the comparator. Its broad threshold surface is nevertheless frozen now so no later implementation may invent a threshold from June results.

`PELT_REFERENCE` remains visible but non-executed at T0 because its newly materialised parameter grid was not covered by the already-frozen measured T0 capacity evidence. Its signal, cost, penalty and minimum-length surfaces are frozen, and its non-execution must appear in failure attribution rather than being silently omitted.

## 3. Parameter-grid provenance

The directional-change threshold grid and PELT penalty/minimum-length grid are **preregistration design choices**, not source-derived claims of optimality. They are deliberately frozen before any June scientific output is generated or inspected. Public/OVC source material establishes that these methods are parameter-sensitive and that sensitivity must be preregistered; it does not establish a uniquely correct GBP/USD threshold or PELT penalty.

## 4. Capacity consequence

The v0.3 June segmentation branch executes only run/change and null control, both linear in the ordered C2 stream and neither feeds the family grid because the frozen real-source C2E aggregate/hybrid representation dependencies remain unavailable. Any future decision to execute PELT or directional change in a market run requires the missing dependency/capacity evidence and a new preregistration version or other explicitly governed authority that binds the exact change.
