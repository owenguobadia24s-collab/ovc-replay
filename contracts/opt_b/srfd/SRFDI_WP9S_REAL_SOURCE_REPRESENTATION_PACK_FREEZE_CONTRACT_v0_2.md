# SRFDI-WP9S Real-Source Representation Pack and Preregistration Remediation Contract v0.2

## Status and authority

`SRFDI-WP9S` is authorised only by the operator decision `OVC APPROVE SRFDI-G9S SUPERSEDE`.
It supersedes the frozen G9 v0.1 preregistration **for execution only** while preserving that historical object byte-for-byte.
This packet may define exact real-source RepresentationPack specifications from frozen C2/C2E contracts and synthetic/schema fixtures.
It grants no June execution, provider intake, Validation use, method/family promotion, selector change, publication, probability, risk, exposure or execution authority.

## 1. Source boundary

1. The only admissible C2 source envelope is the schema-preserving `SRFDI-WP2C` adapter output.
2. Pack construction and QA MUST NOT read the June benchmark population, provider bytes, Validation 2025, family outputs, distance outputs, clustering outputs or stability outputs.
3. Population membership remains independent of representation computability. Lawful `NOT_EVALUATED`, `NOT_EVALUABLE`, `CENSORED`, `CONFLICT` and `QUARANTINED` C2 states remain in the target population and may be representation-specific non-computable records.
4. Every source component is named by stable schema path and deterministic transform. Generic feature discovery is forbidden.

## 2. Exact pack dispositions

The candidate registry `real_source_representation_packs_v0_2.json` is normative for the proposed v0.2 preregistration.

- `SRFDI-R1 RAW_C2`: five frozen C2 categorical axis values; Gower mixed only; any null required value is representation-non-computable.
- `SRFDI-R2 C2E_AGGREGATE`: `DEPENDENCY_UNAVAILABLE` because no lawful active/frozen real-source C2E ledger exists.
- `SRFDI-R3 ORDERED_TRANSITIONS`: `DEPENDENCY_UNAVAILABLE` because the current distance engine has only single-numeric-channel DTW while the frozen C2 transition surface is mixed typed. No ordinal encoding may be invented.
- `SRFDI-R4 NORMALIZED_PATH`: exact candidate channels are LOCATION, MOTION and ORGANISATION measurements, but execution is `DEPENDENCY_UNAVAILABLE` until a separately frozen pre-benchmark non-target min-max fit artifact exists. Target-window fitting and zero imputation are forbidden.
- `SRFDI-R5 HYBRID`: `DEPENDENCY_UNAVAILABLE` because its episode/static and typed-sequence parents are unavailable.
- `SRFDI-R6 ABLATION`: exactly five leave-one-axis-out R1 variants. All variants are preregistered; no post-result best ablation may be selected.
- `SRFDI-R7 CONTEXT_VARIANTS`: `DEPENDENCY_UNAVAILABLE` because WP2C exposes no operator-frozen higher-scale parent context and no parent may be inferred.
- `SRFDI-R8 MISSINGNESS_AWARE`: five explicit categorical status/value tokens. A null value becomes `MISSING::<status>::<reason_code>`; this is missingness encoding, not numeric imputation.
- `SRFDI-R9 NULL_CONTROL`: record-identity-only null control with no market-structure feature.

Unavailable packs remain visible in the configuration audit ledger with their preregistered reason and may not be silently substituted.

## 3. Comparability and distance

Available v0.2 real-source packs require equality of instrument, side, clock, source representation schema, source quality and exact representation pack/variant.
Date is occurrence context only.
`GOWER_MIXED` is the only currently lawful distance for available R1/R6/R8/R9 packs.
L1, L2 and DTW remain registered benchmark candidates but are not configuration-compatible with the currently available real-source packs.
This compatibility restriction is preregistered before benchmark visibility and does not promote Gower.

## 4. Normalization

R4 uses the existing frozen `MINMAX_V0_1` implementation only after a separate pre-benchmark fit artifact is bound.
The fit population must be non-target, the fit cutoff must be no later than `2026-06-01T00:00:00Z`, frozen bounds are transported without refit, and the fit artifact hash is part of configuration identity.
Until such an artifact exists R4 is non-runnable; no default constants or target statistics may be substituted.
