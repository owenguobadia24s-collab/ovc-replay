# EC1 F0 Prelaunch No-Surprises Contract v0.1

## Purpose

`EC1-F0-PRELAUNCH-NO-SURPRISES` is a bounded non-evidentiary execution-hardening packet under the already-ratified EC1 DMRP programme. It reduces avoidable launch failures before the existing F0-A HOLD is released.

## Authority

The packet may inspect current repository records, validate exact source/semantic bindings, run synthetic/adversarial rehearsals, exercise crash/restart and fault-injection paths, measure host/runtime readiness, and emit non-scientific prelaunch evidence.

It MUST NOT:
- release the F0-A HOLD;
- consume F0-A or E1 real-source scientific evidence;
- change EC1-G1 questions, identity fields, search lattice, selector, clocks, sides, instrument, interval, C2 package, C2E boundary pack, or scientific parameters;
- use C2P as a Path-1 seed, filter, repair input, or promotion criterion;
- freeze candidates, consume Validation, publish canon/R2, or create probability/risk/exposure/trading/execution/agent-write authority.

## Blocking checks

Prelaunch qualification fails closed unless all are true:

1. `DMRPI-GREAL-EC1` remains bounded-authorised and the Research Operations append grant remains bounded.
2. F0-A HOLD remains active and requires explicit operator resume/supersession.
3. The active spine remains `OPT-A -> OPT-B.C1.v2 -> OPT-B.C2.vNext -> OPT-B.C2E.v0.2`.
4. C2 package and C2E boundary-pack identities equal the frozen EC1 bindings.
5. Every identity-manifest source path is reachable in the repository.
6. The EC1 search pack remains direct structural canonicalization with no normalization, distance, learned similarity, hidden top-N, or candidate-strength threshold.
7. The F0 selector remains deterministic and scientific parameter tuning remains forbidden.
8. Exact 2021-2023 current C2-vNext/C2E source materialisation is reproducible, hash-bound, unsampled, full precision, and conflict-free.
9. PRSC preregistration remains frozen pre-E1 and has inspected no decision-bearing E1 evidence.
10. The C2P Path-1 influence and disclosure firewalls remain closed.
11. Stage dependency, checkpoint/restart, artifact, source, shard, and blinded-observability checks pass.

## Rehearsal

Synthetic rehearsal MUST traverse the exact semantic stage order used by EC1:

`SOURCE_HYDRATION -> C2_VNEXT -> C2E -> P1_DENOMINATOR_CONSTRUCTION -> PREDICATE_COMPILATION -> PATTERN_LATTICE -> CORE_CLOSURE_EXTRACTION -> ADVERSARIAL_REVIEW -> REVIEW_PACKET`.

Injected process failure followed by checkpoint resume MUST produce the same terminal logical hash as a clean run. Corrupt or drifted checkpoints fail closed.

## Completion

A PASS produces `PRELAUNCH_QUALIFIED_AWAITING_C2P_CLOSEOUT_AND_LAUNCH_SEAL`. F0-A remains on HOLD. After the C2P sidecar closes, a separate currentness-only launch seal may re-resolve main and, only under explicit operator release, supersede the HOLD.
