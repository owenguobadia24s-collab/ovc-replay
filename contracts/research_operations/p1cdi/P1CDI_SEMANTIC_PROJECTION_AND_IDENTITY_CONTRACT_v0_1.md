# P1CDI semantic projection and identity contract v0.1

P1EmpiricalDistinctionSeries identifies a continuing research lineage. P1EmpiricalDistinctionGeneration freezes one immutable empirical meaning. Exact rediscovery under the same compatible P1CDISemanticProjectionProfile attaches evidence to the existing generation; material semantic change creates a successor generation or separately reviewed lineage.

Identity-bearing content is limited to the profile-declared unit type, structural predicates/relations or complete minimal-core set, applicability/scope, identity-defining dependencies, first-valid semantics, missingness semantics, and representation/method/boundary dependencies that are part of the proposition. Recurrence counts, QA, evidence maturity, worker, path, branch, PR, run attempt, cache, and physical integration provenance are excluded.

Only byte-identical canonical projections under the same compatible profile may auto-resolve EXACT_EQUIVALENT. Similarity, labels, embeddings, occurrence overlap, or representation analogues never auto-merge. Profile changes that can alter equality create a new profile generation and explicit correspondence; historical IDs are never silently rehashed. Multiple inclusion-minimal cores remain MULTIPLE_PLAUSIBLE_CORES.
