# RO4 Count-Only Presentation Contract v0.1

Status: `PROPOSED_AT_RO4_G0`

Plan: `OVC-RESEARCH-OPERATIONS-FOUNDATION-v0.4-C2-STATE-SEQUENCE-EVIDENCE-IMPLEMENTATION-PLAN-0.2`

Permanent banner:

`DESCRIPTIVE COUNTS ONLY - counts are not probabilities, likelihoods, forecasts or transition expectations.`

Every operator-facing count appears as an exact integer numerator with the eligible denominator visible in the same cell or row. Excluded and missing counts are explicit and tied to reason inventories and exact slice identity.

Percentages, decimal ratios, normalized frequencies, ranked likelihoods, pie charts, heatmaps, colour gradients, frequency-scaled bars, distribution-shaped styling and descending-frequency default sort are prohibited. Default order follows frozen identity order. Styling is uniform and non-data-driven.

Machine QA may calculate normalized values solely to test concentration thresholds, but those derived values cannot enter operator projection schemas.
