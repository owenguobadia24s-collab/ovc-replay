# RO4 Matrix, Persistence and Conflict Contract v0.1

Status: `PROPOSED_AT_RO4_G0`

Plan: `OVC-RESEARCH-OPERATIONS-FOUNDATION-v0.4-C2-STATE-SEQUENCE-EVIDENCE-IMPLEMENTATION-PLAN-0.2`

Transition matrices are descriptive counts for one exact declared slice. Every operator-facing cell is an exact integer count with the eligible denominator visible in the same cell or row, plus excluded and missing counts. Percentages, normalized frequencies, probability vocabulary, smoothing, imputation, heatmaps, gradients, frequency-scaled bars and descending-frequency default sort are prohibited.

Persistence runs are maximal contiguous intervals for a full vector, one named axis, a frozen instability condition or declared cross-scale alignment. Any relevant change, gap, context break, missing parent or release boundary terminates a run.

Conflict is a vector of predicates frozen from `C2_CONFLICT_AND_AMBIGUITY_POLICY_v0_1`. It lists participating axes, exact values, evidence, chronology and missingness. `NO COMPOSITE SCORE`: no winner, severity score, defect rank or tuning recommendation.

Any operator-facing conflict review requires real matched non-conflict controls and counterevidence.
