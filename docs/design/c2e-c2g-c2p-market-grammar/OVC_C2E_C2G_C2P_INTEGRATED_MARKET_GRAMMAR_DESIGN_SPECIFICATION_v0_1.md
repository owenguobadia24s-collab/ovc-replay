# OVC C2E–C2G–C2P Integrated Market-Grammar Design Specification v0.1

**Document ID:** `OVC-C2E-C2G-C2P-INTEGRATED-MARKET-GRAMMAR-DESIGN-0.1`  
**Programme:** `OVC-C2E-C2G-C2P-MARKET-GRAMMAR-REMEDIATION-v0.1`  
**Status:** `SHADOW_EXPERIMENT_DESIGN_FROZEN_FOR_IMPLEMENTATION`  
**Authority:** bounded inactive, noncanonical research computation only  
**Prepared against main:** `372b072959863957d80c4dc12f393ae97bba482e`

## Executive decision

Build one additive, one-way market-grammar chain:

```text
OPT-A
  -> C1
  -> revised C2 states, relations and transitions
  -> C2E variable-duration episodes
  -> C2G state, transition, episode and multi-scale families
  -> immutable candidate grammar fixtures
  -> C2P deterministic parsing
  -> later operator-reviewed C3 meaning
```

C2.5 remains an independent deterministic event-projection layer. C2P may read a frozen
C2.5 event record as an optional typed token, but C2P must retain direct lawful access to
C2 and C2E structural records. No component in this programme is active, canonical,
selector-addressable, outcome-bearing or exposure-authoritative.

The design corrects the current single-medoid-star and frequency-to-conjunction
interpretations without discarding the real observational nucleus: a medoid remains a real
representative member, but family identity is established by a versioned sensitivity
surface, invariant core, dispersion, stability, hierarchy, variants, counterexamples and
residuals.

## Governing invariants

1. **One-way records.** C2E does not define boundaries from C2G; C2G never rewrites C2 or
   C2E; C2P never mutates the grammar release it applies.
2. **First-valid chronology.** Every edge satisfies `parent_first_valid_time <=
   child_first_valid_time`; unavailable context is explicit.
3. **Identity independent of environment.** Canonical identity excludes local path,
   machine name, process ID, wall-clock run time and unordered iteration.
4. **No outcome-first construction.** No outcome, return, MFE/MAE, success label,
   probability, eligibility or exposure field may affect episode, family, variant or
   grammar construction.
5. **Typed evidence only.** Grammar operators are emitted only when their required
   upstream records and typed domains exist.
6. **Missingness is not neutrality.** `CONTEXT_UNAVAILABLE`, `STALE`,
   `NOT_EVALUABLE`, `CENSORED` and `AMBIGUOUS` remain distinct.
7. **No threshold canonisation.** Sensitivity packs are comparison objects, not active
   selectors.
8. **Contracts remain mutable until topology proof.** Interfaces are
   `SHADOW_EXPERIMENT` through the integrated real-component smoke; a later non-reserved
   design-freeze may stabilise them, but activation remains operator-reserved.

# MG-D1 — Research-friction and defect diagnosis

## D1.1 Family defect

The current output collapses a sensitivity-dependent neighbourhood into a definitive
natural family represented by one medoid star. This overstates what the algorithm proves.
A medoid proves only that one real member minimises the selected aggregate distance under
one frozen population, feature surface and sensitivity configuration.

Remediation:

```text
sensitivity pack
 -> candidate partition / assignment
 -> cross-pack overlap graph
 -> family stability object
 -> invariant core
 -> representative family medoid
 -> FamilyVariant objects and variant medoids
 -> ambiguity, residual and counterexample ledgers
```

## D1.2 Rule compiler defect

The current component-frequency surface classifies high non-common frequency as
`CONTRADICTORY`, then compiles common/invariant components into conjunctions. This mixes
four distinct phenomena:

- genuine logical conflict;
- lawful normal variation;
- high-cardinality identity/provenance variation;
- missingness/computability variation.

The corrected classifier is:

`INVARIANT`, `COMMON`, `NORMAL_VARIATION`, `HIGH_CARDINALITY_VARIATION`,
`MISSINGNESS_VARIATION`, `LOGICAL_CONFLICT`, `OPTIONAL`, `RARE`.

`LOGICAL_CONFLICT` is allowed only when a versioned exclusivity registry proves mutual
exclusion for the same feature, object, scope and first-valid time.

## D1.3 Domain contamination

Structural matching must not be altered by source release IDs, hashes, record IDs,
provider names, clock identifiers or computability status. These remain required lineage
or applicability information but are not market structure. Candidate grammar therefore
has six typed domains:

- `STRUCTURAL`
- `TEMPORAL`
- `OBJECT_BINDING`
- `CONTEXT`
- `COMPUTABILITY`
- `PROVENANCE`

## D1.4 Temporal deficit

A per-observation conjunction cannot express a developing path. C2E is therefore required
as the owner of variable-duration episode identity, ordered phase segments,
interruptions, termination, nesting, completion and censoring. C2P then consumes those
records through typed sequence operators rather than inferring sequences from unordered
features.

# MG-D2 — Shared identity, object and lineage model

Every durable object carries:

```text
record_id
record_type
schema_version
contract_version
first_valid_time
source_release_id
parent_record_ids
parameter_pack_id
content_sha256
authority_state
lineage
missingness
```

## Canonical identity

`record_id = namespace + "." + sha256(canonical_payload_without_environment_fields)[:24]`

Canonical payload rules:

- UTF-8;
- sorted object keys;
- arrays sorted only when the contract declares them unordered;
- decimal values rendered as canonical strings;
- timestamps normalised to UTC `Z`;
- no absolute paths, machine names, transient run IDs or creation times;
- upstream IDs and exact contract/pack versions included;
- `None` remains explicit and is never dropped when semantically meaningful.

## Shared object types

- `C2StateRef`, `C2RelationRef`, `C2TransitionRef`
- `C2EEpisode`, `C2EPhaseSegment`, `C2EInterruption`
- `C2GFamily`, `C2GFamilyEdge`, `C2GFamilyVariant`, `C2GAssignment`
- `C2GTransitionFamily`, `C2GEpisodeFamily`, `C2GMultiClockFamily`
- `C2PGrammarRelease`, `C2PGrammarNode`, `C2PParseResult`
- `ContextAlignment`, `MissingEvidence`, `ConflictEvidence`
- `ExternalArtifactRef`, `QAAsssertion`, `DecisionRecord`

Lineage is append-only. A downstream object may record an upstream defect but may not
repair or relabel the upstream record.

# MG-D3 — C2E episode architecture

C2E is a deterministic ledger. It groups lawful ordered C2 records without using C2G
membership or outcomes.

## Episode lifecycle

`OPEN -> CONTINUING -> INTERRUPTED -> CONTINUING | COMPLETED | TERMINATED |
CENSORED | UNRESOLVED`

Required times:

- `episode_start_time`: first record considered part of the episode;
- `first_valid_time`: time at which the existence of the episode is lawfully knowable;
- `phase_first_valid_time`;
- `completion_first_valid_time`;
- `closed_time` when the ledger ceases extension.

## Boundary sources

An episode boundary policy may use only:

- typed C2 state transitions;
- typed relation transitions;
- object continuity;
- clock profile;
- explicit interruption tolerance;
- computability and context availability.

It may not use family labels, grammar matches, future path, outcomes or operator semantic
labels.

## Episode contents

- ordered `phase_segments`;
- run length and dwell by state/phase;
- interruption records distinguished from termination;
- unresolved and censored states;
- parent/child nesting;
- object continuity bindings;
- ambiguity ledger;
- explicit `NOT_EVALUABLE` reason;
- completion evidence and invalidation evidence.

A nested child episode may begin within a parent episode, but both identities are
independently reproducible. Parentage is an edge, not a field that changes the child’s
structural content hash.

# MG-D4 — C2G family sensitivity, hierarchy and variant architecture

## C2G-S — sensitivity packs

A sensitivity pack freezes:

- distance metric and feature-domain allowlist;
- feature weights;
- missingness policy;
- assignment radius;
- ambiguity margin;
- minimum support;
- variant radius;
- stability overlap thresholds;
- deterministic tie-break ordering.

Initial comparison packs include `0.20`, `0.35`, `0.50` and lawful nearby values.
No pack is canonical.

## C2G-H — family hierarchy DAG

Each sensitivity-specific family is a node. Cross-pack relationships are directed,
versioned edges:

- `PARENT_OF`
- `CHILD_OF`
- `VARIANT_OF`
- `PARTIAL_OVERLAP_WITH`
- `SUPERSEDES`

The graph must remain acyclic for all directional containment/supersession edges.
`PARTIAL_OVERLAP_WITH` is represented as a symmetric pair or a separately typed
non-hierarchical relation excluded from DAG cycle checks.

Measurements:

- member containment;
- Jaccard overlap;
- medoid persistence;
- dispersion;
- reassignment rate;
- split/merge events;
- survival across adjacent sensitivities;
- counterexample retention.

## C2G-V — FamilyVariant

A `FamilyVariant` is a recurring, stable substructure within a candidate family. It owns:

- invariant structural core;
- variant-specific lawful differences;
- real variant medoid;
- support and dispersion;
- stability across sensitivity packs;
- residual and counterexample members;
- parent family edge.

Variants are not generated from provenance or identity fields.

## C2G-A — assignment ledger

Every observation/transition/episode is one of:

- `ASSIGNED`
- `AMBIGUOUS`
- `RESIDUAL`
- `UNASSIGNED`
- `NOT_EVALUABLE`

The ledger records all candidate distances, deterministic tie-break facts, nearest family
and variant, and reason codes.

## C2G-T / C2G-E / C2G-M

- `C2G-T` discovers families over typed transition records.
- `C2G-E` discovers families over C2E episodes and their phase paths.
- `C2G-M` discovers lawful multi-clock parent/child structures from aligned records.
- Each uses its own type-specific feature contract; object types are never mixed by an
  untyped common vector.

# MG-D5 — C2P typed grammar and parser architecture

## AST operators

- `ALL_OF(children)`
- `ANY_OF(children)`
- `SEQUENCE(children)`
- `WITHIN_N_OBSERVATIONS(n, child)`
- `SAME_OBJECT(binding, children)`
- `RELATION_TRANSITION(from, to, object_binding)`
- `RUN_LENGTH(min, max, child)`
- `CONTEXT_AVAILABILITY(required_state)`

Each node declares:

```text
operator
input_type
output_type
domain
required_fields
children
parameters
```

The compiler rejects an operator if its required intermediate record or typed field is
absent.

## Layered declarative grammar

A grammar release may contain:

`context -> location -> condition -> episode phase -> event -> response -> transition ->
possible resolution -> invalidating conditions`

The layers are not all mandatory, but absence is explicit and typed.

## Parser outputs

- `NO_MATCH`
- `PARTIAL_MATCH`
- `AMBIGUOUS_MATCH`
- `GRAMMAR_MATCH`
- `GRAMMAR_CONTRADICTION`
- `GRAMMAR_INVALIDATED`

Every result retains:

- frozen grammar release ID/hash;
- nearest family and variant;
- distances to family and variant medoids;
- current/completed phases;
- lawful next phases;
- missing evidence;
- conflicting evidence;
- invalidation reasons;
- complete upstream lineage.

`GRAMMAR_CONTRADICTION` requires an exclusivity-registry proof or explicit invalidating
condition; ordinary variation cannot produce it.

# MG-D6 — Multi-clock and parent-context architecture

Initial clock profile:

```text
evaluation_clock = 15M
context_clock = 2H_A_L
relationship = PARENT_CONTEXT
```

Alignment:

1. choose the latest parent record whose `first_valid_time <=
   child.first_valid_time`;
2. reject a parent from a different release/side/instrument/profile;
3. evaluate staleness against the frozen clock profile;
4. emit one of `AVAILABLE`, `CONTEXT_UNAVAILABLE`, `STALE`, `NOT_EVALUABLE`;
5. never convert unavailable context to a neutral structural predicate.

Parent context is typed `CONTEXT`; it does not become a structural feature unless a
grammar node explicitly references a lawful parent structural field.

The June replay warning—zero 2H rule matches—prevents any claim that multi-clock grammar
is empirically established. This programme may implement and smoke-test the alignment and
typed grammar topology only.

# MG-D7 — Integrated vertical-slice topology and smoke design

Required topology:

```text
revised C2 fixture/accepted record
 -> C2E episode construction
 -> C2G state and transition families
 -> hierarchy and FamilyVariant discovery
 -> C2G episode grammar candidate
 -> immutable grammar fixture
 -> C2P parse
 -> typed read-only projection
```

Smoke acceptance:

- two executions produce byte-identical canonical outputs;
- shuffled input order produces the same result after lawful chronology sort;
- local path and machine labels do not affect IDs;
- provenance-inclusive matching differs only in a diagnostic ablation surface and never
  in structural family assignment;
- missing parent context yields explicit context status;
- no operator is emitted without typed evidence;
- the original fourteen candidates each receive one of:
  `MAPPED`, `SUPERSEDED`, `QUARANTINED`, `UNRESOLVED`;
- runtime and retained output remain inside 14,400 seconds and 10 GiB unless
  `CAPACITY_EXCEEDED` is emitted.
