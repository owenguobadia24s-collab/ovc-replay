# OVC OPT-D Repeated-Story Evidence Contract v0.1

**Contract ID:** `OPT-D-STORY-0.1`  
**Parent:** `OPT-D-CONTRAST-0.1`  
**Status:** `RATIFIED FOR DESCRIPTIVE STORY EVIDENCE PACKS`

## Admission and exclusions

All and only contrasts labelled `DESCRIPTIVE_CONTRAST_READY` are admitted. The
complete non-ready set is materialized in an exclusion ledger with its parent
readiness reason. Temporal delta sign is never an admission criterion.

## Frozen story grammar

Every admitted outcome receives one archetype based on:

- event clock, horizon, broad event-family set and event direction;
- endpoint alignment and favourable/adverse excursion dominance;
- first path extreme and continuation state;
- primary-frontier outcome;
- endpoint position by fixed range thirds.

Exact semantic event signatures, endpoint acceptance/displacement/compression/
interaction/quality states and transition-axis patterns remain hashed lineage
annotations on every membership and archetype. They do not fragment otherwise
equivalent qualitative stories. Exact prices, returns, level IDs and record IDs
also do not fragment archetypes.

This two-layer rule prevents compound event/state detail from manufacturing a
different “story” for nearly every outcome while retaining a deterministic path
back to every exact semantic source record.

## Repetition labels

Repetition is based only on distinct overlap-cluster coverage:

- one cluster: `SINGLETON_INVENTORY`;
- two clusters: `REPEATED_MINIMAL_SUPPORT`;
- three to nine clusters: `REPEATED_LIMITED_SUPPORT`;
- ten or more clusters: `REPEATED_DESCRIPTIVE_SUPPORT`.

These labels describe recurrence and cluster diversity only. They do not assert
independence, probability, reliability or edge.

## Evidence packs

Each admitted contrast receives one pack containing both exclusive arms, shared
cluster evidence, archetype support, the complete parent monthly profile,
counterexample coverage and explicit failure conditions. Every arm membership
is materialized with its archetype ID.

The five most cluster-supported archetypes per arm are reported. This is a
coverage summary, not a favourable-story ranking.

## Representative cases

Cases are selected from one canonical row per overlap cluster. The canonical
row is closest to that cluster's median primary metric. Fixed roles are:

- central (50th percentile target);
- lower-tail (10th percentile target);
- upper-tail (90th percentile target);
- central opposite-direction endpoint counterexample, when present;
- central primary-frontier-loss case, when present.

Standard roles use distinct clusters when possible. Case selection cannot use
profit, edge, operator preference or post-hoc narrative appeal.

## Failure conditions

Packs must expose opposite-direction endpoints, primary-frontier loss on close,
mixed monthly contrast signs, insufficient monthly support, shared overlap
clusters and any absent primary frontier. None is a trade-loss label.

## Prohibitions

This release cannot omit counterexamples, select only sign-consistent
contrasts, infer probability or independence, optimize thresholds, establish
edge, recommend action, size risk or authorize trading, production or
execution. The 24h horizon remains coverage-only and 48h remains blocked.
