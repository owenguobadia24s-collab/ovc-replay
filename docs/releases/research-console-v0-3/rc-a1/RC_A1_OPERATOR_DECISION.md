# RC-A1 — v0.3 Information-Architecture Amendment Acceptance

**Decision: PASS — the OVC Research Console v0.3 unified-workspaces information architecture is accepted.**

## Accepted structure

The console has exactly three primary workspaces:

- `OVERVIEW`
- `RESEARCH`
- `SYSTEM`

The fourteen v0.2 routes are not retained as competing top-level navigation. Each route has one explicit workspace, panel or global-surface destination. Historical v0.2 IDs may exist only as non-authoritative compatibility aliases.

## Accepted global interaction contract

The v0.3 shell may implement, from fixtures only:

- a compact workspace rail and workspace tabs;
- a persistent represented-context header and context bar;
- a contextual detail drawer;
- a read-only command palette;
- ambient multidimensional health;
- a persistent source-derived activity stream;
- a non-clickable `LOCAL` authority badge.

Workspace and drawer changes preserve lawful global context. `PROSPECTIVE` mode denies post-cutoff evidence. `REVIEW` mode may expose later evidence only through a separate, explicitly labelled surface.

## Safety acceptance

The v0.2 status vocabulary, empty-state truth rules, source-resolution requirement and fail-closed laws remain inherited. No signal cannot become `PASS`; unknown status falls back to `BLOCK`; colour-only status and unregistered actions remain prohibited.

The amendment introduces no repository, selector, threshold, release, market, probability, exposure, trading, execution, agent or remote-deployment authority. Research-record writes remain separately gated.
