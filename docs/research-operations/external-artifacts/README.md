# OVC Research Operations external-artifact storage

This directory records the existing OVC hybrid storage binding. It does not grant new implementation, scientific, selector, publication, Validation, probability, risk, exposure, trading, execution or agent-write authority.

## Storage roles

- Google Drive `ovc-replay-external-artifacts/research-operations/` stores navigable generated DOCX packages, research materials and bounded release bundles.
- This repository stores compact manifests, SHA-256 identities, schemas, deterministic registries, synthetic fixtures and validation receipts.
- Cloudflare R2 `ovc-evidence/canonical/` remains the canonical immutable evidence-object root where separately governed publication is lawful.
- Operator-local `OVC_EXTERNAL_ARTIFACT_ROOT` remains the execution and staging boundary for generated bytes outside Git.

## EC1 layout

The Drive EC1 root contains ordered sections from interpretation constitution through conditional GSCI/upper-layer packets. Versioned completed bundles live under `03-evidence-cycles/EC1/90-releases/`.

Current package: [OVC_EC1_RV_Preparation_Package_v0_1](https://drive.google.com/drive/folders/1lRgiOzL_GjRcf8x4qxaa-TiZ2DVs-xOg).

Repository binding: `records/research_operations/ec1/EC1_RV_PREPARATION_EXTERNAL_ARTIFACT_INDEX_v0_1.json`.

## Invariants

DOCX and ZIP binaries remain outside Git. Storage never promotes an `UNTESTED` or synthetic object into evidence. Every external binding must carry an exact file ID, byte size and SHA-256; replacement requires a new versioned record rather than silent overwrite.
