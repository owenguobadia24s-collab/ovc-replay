# Repository authority guards

These tests are active repository controls, not market-model tests. They fail the standard CI suite when the active tree imports quarantined code, expands outside the approved package namespace, restores legacy selector authority, reuses old discovery seeds, introduces reverse dependencies or places raw market payloads in active Git storage planes.

Historical court records under `docs/history/` and `legacy/quarantine/` remain addressable but non-authoritative. Changing a guard requires an explicit reviewed repository-authority decision.
